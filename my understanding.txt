
🌾 Project 1: Plant Genomics & Pathology (Tabular ML)1. Data Kahan Se Liya Aur Sample Size Kya Tha?Asal Source: NCBI GEO (Gene Expression Omnibus) ya Kaggle ka tabular dataset (like Arabidopsis ya Rice Disease expression data).Sample Size: Total 801 plants (samples) ka data tha.Features: Isme 5,000 genes ka expression level (numerical rows/columns) tha. Ye high-dimensional data tha ($p > n$ problem).2. Data Ke Saath Pehle Kya Kiya? (Preprocessing)Data ko 80/20 ke ratio mein split kiya: 640 samples training ke liye aur 161 samples testing ke liye rakhe.Pehle StandardScaler se saare expression counts ko normalize (Z-score) kiya taake har gene ka scale barabar ho jaye.3. Feature Selection (Sab Se Important Step):5,000 genes bohot zyada hote hain aur model overfit ho jata. Isliye humne ANOVA F-Test (SelectKBest) algorithm chalaya.Isne un top 50 marker genes ko filter out kar diya jo Resistant aur Susceptible plants ke beech sab se zyada variance show kar rahe the.4. Model Kaunsa Use Kiya Aur Kyun?Model: Support Vector Machine (SVM) with RBF Kernel.Kyun Kiya: Kyun ke biological genomic data non-linear hota hai aur SVM high-dimensional tabular datasets par classification ke liye sab se behtareen model maana jata hai.5. Accuracy Aur Validation Kaise Hui?Overfitting check karne ke liye training data par 5-Fold Cross-Validation chalayi, jisme mean accuracy ~99.4% aayi.Phir final model ko bilkul alag 161 testing samples par evaluate kiya.Advanced Touch: Humne PCA (Principal Component Analysis) run karke un 50 genes ko 2D plot par scatter kiya, jahan Resistant (Green) aur Susceptible (Red) plants ke do alag saaf clusters nazar aaye.Aakhir mein model, scaler, aur selector ko joblib se .pkl file mein save (serialize) kar diya taake baar-baar run na karna pare.
